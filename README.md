# Остров на реке

Процедурная 3D-сцена в браузере: тихий остров посреди реки, лес по берегам, горы вдали, ветер в траве.
Всё нарисовано кодом — без картинок, моделей и звуковых файлов. Вся сцена — один файл `index.html` (~590 КБ), работает без интернета.

**Версия:** 0.0.2 (см. [CHANGELOG.md](CHANGELOG.md))

## Как открыть
- **Компьютер:** скачайте `index.html` и откройте двойным щелчком в Chrome или Edge.
- **Телефон по ссылке:** включите GitHub Pages (ниже) и откройте ссылку вида `https://<логин>.github.io/river_island/`.

### Включить GitHub Pages
1. В репозитории: **Settings → Pages**.
2. **Source:** *Deploy from a branch*, ветка `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты сверху появится ссылка на сайт.

## Управление
- **Телефон:** левая половина экрана — ходьба (джойстик), правая — обзор.
- **Компьютер:** WASD — ходьба, мышь с зажатой кнопкой или стрелки — обзор, Shift — быстрее.
- **Меню** (иконка справа вверху): время суток, длина суток (25 / 15 / 10 мин, пауза), погода (ясно, облачно, пасмурно, туман, дождь, гроза), автопогода, камера (прогулка / облёт), качество (авто / низкое / среднее / высокое), ветер, громкость, часы, счётчик кадров, новый остров.

## Что внутри
| Файл | Что делает |
|---|---|
| `src/main.js` | Рендер, камера и управление, смена суток и погоды, свет, молнии, меню, автокачество |
| `src/world.js` | Рельеф, река и остров, горы, профиль горизонта, деревья, кусты, трава, цветы, камыш, лес на берегах |
| `src/shaders.js` | Шейдеры: небо и облака, вода, ветер, тени облаков, дымка на горах, дождь, светлячки, туман |
| `src/fauna.js` | Бабочки, стрекозы, птицы и летучие мыши, рыбы |
| `src/audio.js` | Синтезированный звук: ветер, река, дождь, гром, птицы, сверчки, лягушки, сова |
| `src/noise.js` | Шумы и процедурные текстуры |
| `template.html` | Разметка, стили, меню |
| `build.sh` | Сборка всего в `index.html` |

## Сборка
Нужны Node.js и Python 3.
```bash
npm install
npm run build   # собирает index.html
```

## Технологии
[Three.js](https://threejs.org/) 0.170 (WebGL), esbuild для сборки, Web Audio API для звука.
